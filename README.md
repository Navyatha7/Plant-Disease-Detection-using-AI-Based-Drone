
🌱 Plant Disease Detection using AI-Based Drone
📌 Overview

This project detects plant diseases using AI-based image processing and drones. Images of crops are captured and analyzed with a Convolutional Neural Network (CNN) model to identify diseases and provide organic & inorganic solutions for prevention.

🚀 Key Features

Upload plant images for disease detection.

AI-driven CNN model for accurate classification.

Provides organic and inorganic treatment options.

Web interface for farmers to view results.

🛠️ Tech Stack

Python (TensorFlow, Keras, NumPy, Pandas)

Flask / Streamlit (interface)

HTML, CSS, JS (frontend)

Database (MySQL / SQLite)

⚙️ How to Run

Clone the repository:

git clone https://github.com/Navyatha7/Plant-Disease-Detection.git
cd Plant-Disease-Detection


Install dependencies:

pip install -r requirements.txt


Run the app:

python app.py


Open in browser: http://127.0.0.1:5000/
